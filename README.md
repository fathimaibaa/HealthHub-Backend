# HealthHub Backend

Advanced healthcare platform backend built with Node.js, Express.js, MongoDB, and TypeScript.

## Core Features

### User Features
- Secure user authentication and authorization
- Doctor search and profile access
- Real-time chat with doctors
- Video consultation / video calling
- Doctor appointment booking system
- Secure online payment integration with Stripe
- Real-time communication for consultation and support
- Appointment history and management

### Doctor Features
- Doctor authentication and profile management
- Add and manage professional descriptions
- Create and publish medical posts/content
- Patient communication through chat and video calls
- Appointment and booking management

### Admin / Platform Features
- Role-based system
- Secure payment handling
- Real-time interaction architecture
- Healthcare service management

## Tech Stack
- Node.js
- Express.js
- MongoDB
- TypeScript
- Stripe
- Real-time Communication (Socket / WebRTC)

## Project Goal
A full-featured digital healthcare ecosystem connecting patients and doctors through booking, communication, and secure online healthcare services.
